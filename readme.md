# ECSI Estetic Center

Static shop-theme demo for the ECSI estetic center webshop.

The theme is a single bundled page (`index.html`) plus images in `assets/`. Open `index.html` in a browser to view the demo. JavaScript unpacks the page on load.

## Layout

- `index.html` — bundled storefront demo
- `assets/` — logo, hero, and showcase images

This folder is its own Git repository: [codexBA/esci-estetic-center](https://github.com/codexBA/esci-estetic-center).
